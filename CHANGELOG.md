## [0.1.0] - YYYY-MM-DD

First public release.

### Added
- Order forecast per product line and size from quarterly sales exports and a stock report.
- Plotly Dash dashboard: order sheet, stock flow, demand history, item risk simulation, context and data tabs.
- SQLite database with idempotent imports, an audit log, full CSV export, restore and automatic backup folder.
- Optional Epos Now API pull (not yet verified against a live account).
- Double-click launchers for Windows, macOS and Linux, and a fictional demo dataset.
- Continuous integration and a tag-driven release workflow.
